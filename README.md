# AI Class Datasets

Public datasets for classroom exercises, labs, and projects
in ThinkBiggerStudio — AI Applications.

## Available Datasets

| File | Description |
|------|-------------|
| emails.csv | Email dataset |
| movies.csv | Movie dataset |
| ratings.csv | Movie ratings dataset |

## Usage

Students may download these files or load them directly
into Python notebooks for classroom activities.

Datasets are provided for educational use.
